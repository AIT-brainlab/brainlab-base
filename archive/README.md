# Archived Legacy Assets (`archive/`)

This directory contains legacy configurations, previous Docker image definitions, static image assets, and old tutorial examples preserved for historical reference.

---

## 📁 Archived Contents

- **`archive/cloud/`**: Pre-reorganization cloud notes and early drafts. (Active management plane now lives in [`mgmt/`](../mgmt/) and workload templates in [`infra/cloud/`](../infra/cloud/)).
- **`archive/api/`**: Legacy API submodules and old Traefik deployment configs. (Active services now live in [`services/api/`](../services/api/)).
- **`archive/docker_images/`**: Legacy Dockerfiles and old JupyterHub scripts. (Active images and config now live in [`services/jupyterhub/`](../services/jupyterhub/)).
- **`archive/examples/`**: Archived notebooks including `mlflow-example.ipynb`.
- **`archive/imgs/`**: Historical architecture diagrams and MLflow screenshots.
